# 日本語 MASTER

한국어 사용자를 위한 브라우저 기반 일본어 학습 앱입니다.

## 현재 버전

**v9**

## 주요 기능

- N5 → N1 → N1+ → MASTER I / II / III → 深淵 단계
- 어휘 · 문법 · 한자 · 독해 학습
- 카드 학습 / 대량 암기용 **암기표 모드**
- 뜻/읽기 가리기, 모름·애매·숙달, 집중 암기 ★
- 급수 진단과 영역별 약점 분석
- 진단 결과 기반 개인 커리큘럼
- 한국어 뜻 캐시 및 백그라운드 준비
- 실제 문헌 출전을 확인한 고전·희귀어 예문
- 모바일 / 폴더블 반응형 UI
- 학습 진척도는 브라우저에 저장

## 실행

저장소의 `index.html`을 브라우저에서 열면 실행됩니다.

GitHub Pages를 `main / root`로 활성화하면 별도 설치 없이 웹앱처럼 사용할 수 있습니다.

## 데이터 관련

JLPT는 2010년 개정 이후 고정된 공식 어휘·한자·문법 목록을 공개하지 않으므로,
앱의 N5~N1 범위는 공개 학습 자료를 바탕으로 구성한 **예상 JLPT 학습 범위**입니다.

MASTER / 深淵은 JLPT 공식 급수가 아니라 고급 일본어 학습을 위한 자체 난도 구분입니다.
